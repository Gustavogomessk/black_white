# Clube Social Esportivo União

## 1. Identificação do Projeto

O Clube Social Esportivo União é um clube voltado para esportes, lazer e convivência social.

**Nome do projeto:** Clube Social Esportivo União (CSEU)

**Tema:** Clube social e esportivo

**Disciplina:** Desenvolvimento Front-End para Web

**Tipo de projeto:** Site institucional fictício

**Nome da equipe:** Black White

## 2. Objetivo do Projeto

O objetivo do projeto é desenvolver um site institucional para o Clube Social Esportivo União, apresentando informações sobre o clube, suas atividades, espaços, eventos, modalidades, unidades e formas de contato.

O projeto também busca aplicar os conhecimentos aprendidos na disciplina de Desenvolvimento Front-End para Web, utilizando HTML5, estrutura semântica, navegação entre páginas, formulários, imagens, tabelas e recursos de estilização com CSS.

## 3. Descrição do Site

O Clube Social Esportivo União é um clube fictício voltado para esportes, lazer e convivência social.

O site apresenta informações sobre a história do clube, modalidades esportivas, estrutura física, eventos, atividades, turmas, reservas, unidades, loja e formas de contato.

Também foi desenvolvida uma página de Política de Privacidade, apresentando informações relacionadas à utilização e proteção dos dados fornecidos pelos usuários durante a utilização do site.

A proposta é criar um ambiente virtual organizado e de fácil navegação, permitindo que os visitantes encontrem as principais informações e serviços oferecidos pelo clube.

## 4. Público-alvo

O site é destinado a pessoas interessadas em esportes, lazer, eventos sociais e atividades recreativas.

O público-alvo inclui visitantes, familiares e pessoas interessadas em conhecer as atividades, modalidades, espaços, eventos e serviços oferecidos pelo clube.

## 6. Estrutura HTML e Semântica

O projeto foi desenvolvido utilizando HTML5, buscando manter as páginas organizadas por meio de uma estrutura clara e do uso de elementos semânticos.

As principais tags utilizadas no desenvolvimento são:

- `<header>`: utilizada para representar o cabeçalho das páginas.
- `<nav>`: utilizada para organizar o menu de navegação e os links entre as páginas.
- `<main>`: utilizada para identificar o conteúdo principal de cada página.
- `<section>`: utilizada para dividir o conteúdo das páginas em diferentes áreas.
- `<footer>`: utilizada para representar o rodapé das páginas.
- `<h1>`, `<h2>` e `<h3>`: utilizadas para criar a hierarquia de títulos e subtítulos.
- `<p>`: utilizada para apresentar textos e parágrafos.
- `<strong>`: utilizada para destacar informações importantes dentro dos textos.
- `<a>`: utilizada para criar links e realizar a navegação entre as páginas.
- `<img>`: utilizada para inserir imagens relacionadas ao conteúdo do clube.
- `<div>`: utilizada para agrupar elementos e auxiliar na organização do conteúdo.
- `<ul>` e `<li>`: utilizadas para apresentar informações em formato de lista.
- `<form>`: utilizada para criar formulários presentes no projeto.
- `<label>`: utilizada para identificar os campos dos formulários.
- `<input>`: utilizada para permitir a entrada de dados pelo usuário, incluindo campos de texto, e-mail, data e horário.
- `<select>` e `<option>`: utilizadas para criar campos com opções de seleção.
- `<textarea>`: utilizada para campos que permitem a inserção de textos maiores e observações.
- `<button>`: utilizada para criar botões de ação nas páginas e formulários.
- `<table>`: utilizada para organizar informações em formato de tabela.
- `<tr>`: utilizada para representar as linhas das tabelas.
- `<th>`: utilizada para representar os títulos das colunas.
- `<td>`: utilizada para representar os dados presentes nas tabelas.

A utilização dessas tags contribui para uma estrutura mais organizada, facilita a compreensão do código e permite separar corretamente as diferentes áreas e funcionalidades presentes no site.

## 7. Estilização com CSS

O projeto utiliza CSS para definir a aparência visual e a organização dos elementos presentes nas páginas.

Foram utilizados seletores de elementos, classes e propriedades de estilização para manter uma identidade visual semelhante entre as diferentes páginas do site.

Entre os principais recursos utilizados estão:

- `background-color`: utilizada para definir as cores de fundo das páginas e componentes.
- `color`: utilizada para definir a cor dos textos.
- `font-family`: utilizada para definir as fontes dos conteúdos.
- `font-size`: utilizada para controlar o tamanho dos textos.
- `width` e `height`: utilizadas para definir dimensões de elementos, imagens e componentes.
- `margin` e `padding`: utilizadas para controlar os espaçamentos externos e internos.
- `border-radius`: utilizada para criar bordas arredondadas.
- `box-shadow`: utilizada para adicionar sombras aos elementos.
- `text-align`: utilizada para controlar o alinhamento dos textos.
- `display: flex`: utilizada para organizar e alinhar elementos por meio do Flexbox.
- `flex-direction`: utilizada para definir a direção dos elementos dentro de um container Flexbox.
- `align-items`: utilizada para controlar o alinhamento dos elementos.
- `justify-content`: utilizada para distribuir e posicionar os elementos.
- `gap`: utilizada para criar espaçamento entre elementos.
- `object-fit`: utilizada para ajustar a exibição das imagens dentro de seus espaços.
- `position`: utilizada para controlar o posicionamento de determinados elementos, como a logomarca.

Também foram criadas diferentes classes CSS para estilizar menus de navegação, cards, formulários, tabelas, eventos, áreas do clube, reservas, loja e outros componentes das páginas.

O uso do CSS permite separar a estrutura criada em HTML da apresentação visual do projeto, facilitando a organização, manutenção e personalização das páginas.

## 8. Páginas do Projeto

O site é composto por diferentes páginas HTML, cada uma destinada a apresentar uma área ou funcionalidade específica do Clube Social Esportivo União.

Entre as páginas desenvolvidas estão:

- **Página Inicial:** apresenta as principais informações e opções de navegação do site.
- **Clube:** apresenta informações institucionais, história, missão, visão, valores e estrutura do clube.
- **Atletas:** apresenta informações relacionadas aos atletas e modalidades esportivas.
- **Contato:** disponibiliza informações de contato e formulário para envio de mensagens.
- **Modalidades:** apresenta as modalidades esportivas disponíveis no clube.
- **Turmas:** apresenta informações sobre turmas, horários, categorias e vagas.
- **Reservas:** apresenta os espaços disponíveis e opções relacionadas às reservas.
- **Orçamento:** apresenta informações e opções relacionadas à solicitação de orçamento.
- **Eventos:** apresenta eventos esportivos, shows, torneios e confraternizações realizados pelo clube.
- **Loja:** apresenta roupas, calçados e artigos esportivos relacionados ao clube.
- **Unidades:** apresenta as diferentes unidades fictícias do CSEU, seus endereços, horários e estruturas.
- **Política de Privacidade:** apresenta informações sobre coleta, utilização e proteção de dados dos usuários.

Também foram desenvolvidas páginas de confirmação para ações realizadas no site, como envio de mensagens, solicitações e reservas.

## 9. Organização dos Arquivos

O projeto foi organizado em diferentes pastas e arquivos para facilitar o desenvolvimento e a manutenção.

A estrutura utiliza:

- `css/`: arquivos responsáveis pela estilização das páginas.
- `img/`: imagens utilizadas no projeto.
- `docs/`: arquivos relacionados à documentação do projeto.
- Arquivos `.html`: páginas que compõem o site.
- `README.md`: documentação principal do projeto escrita em Markdown.

Essa organização facilita a localização dos arquivos e mantém o projeto estruturado.
